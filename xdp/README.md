# Ограничитель начальных IPv4 TCP SYN

Правило применяется к SYN=1, ACK=0 всех TCP-портов. Для каждого source IP
первые THRESHOLD пакетов фиксированного окна получают XDP_PASS, остальные XDP_DROP.
По умолчанию THRESHOLD=100, WINDOW_NS=1000000000. Границы окон привязаны к IP.

```bash
make xdp-all
make xdp-stats
make xdp-dashboard
make xdp-unload
make xdp-all THRESHOLD=200
```

## Карты и телеметрия

syn_windows — hash-map до 1024 адресов. Значение содержит spin lock, оконный count
и start_ns. Неуспешное добавление нового адреса приводит к DROP и росту map_full.
Автоматического удаления старых адресов нет; перезагрузка программы очищает карты.

xdp_stats — per-CPU array накопительных u64:

| Индекс | Имя | Значение |
|---|---|---|
| 0 | syn | Распознанные начальные SYN |
| 1 | pass | Пропущенные начальные SYN |
| 2 | drop | Отброшенные начальные SYN |
| 3 | map_full | SYN, отброшенные при невозможности добавить IP |
| 4 | fragment_drop | Отброшенные IPv4 TCP фрагменты |

Карты закреплены в /sys/fs/bpf/opla/maps. collect.py суммирует CPU и проверяет
ID закреплённой программы против ID на ens3. TUI считает скорость по монотонным
часам. Ни TUI, ни Zabbix не читают trace_pipe.

Native пробуется первым, generic — при ошибке привязки native. Ошибки загрузки
BPF не скрываются fallback. Сборка содержит BTF через -g; использование
bpf_helpers.h само по себе не означает наличие CO-RE relocations.

## Ограничения

IPv4 options и два VLAN-тега разбираются. Фрагментированный IPv4 TCP запрещён.
IPv6/UDP этим правилом не ограничиваются. Часть повреждённых заголовков
отбрасывается без изменения счётчика SYN. NAT объединяет лимиты клиентов,
распределённый поток может пройти, а заполнение hash-map блокирует новых клиентов.
Это учебный алгоритм, а не универсальная DDoS-защита. Измерений ускорения нет.

## Проверка

make check выполняет реальную C-функцию с подменой BPF helpers и clock.
Для проверки ядра обязательны make xdp-build и make xdp-load на victim.
Контрольный сценарий и требования к доказательствам находятся в docs/acceptance.md.
