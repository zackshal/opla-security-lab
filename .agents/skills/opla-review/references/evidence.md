Treat prose and agent-provided PASS as claims. Require exact command, working directory, baseline/content hash, exit status, timestamps and captured log digest. Check current-tree compatibility and inspect failed/blocked tests. A zero exit code alone does not certify the kernel verifier, VM isolation or live telemetry. Native usage is the only source for token/cost metrics; unavailable values stay null. Local task JSON is not tamper-proof attestation. Interrupted/running records require reconciliation; do not blindly replay. Safety changes require an independent reviewer and explicit human activation after fixture comparison. Hooks can be skipped, disabled, error or miss tool paths; they are defense in depth only.
