# Данные и удаление

Сначала экспортируйте reports/evidence, затем остановите monitoring и lab.
Удаление требует точного подтверждения lab ID; при ошибке stop удаление
отклоняется.

## 9. Удалить все зарегистрированные лаборатории

Массовое удаление не является автоматической операцией acceptance. Получите
список, обработайте каждый ID отдельной ownership-aware командой и остановитесь
при первой ошибке. Не используйте glob, prefix или `latest`.
