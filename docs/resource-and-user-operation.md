# Ресурсы и обычный пользователь

Непривилегированный пользователь запускает read-only проверки и CLI; sudo
ограничен привилегированными lifecycle-действиями. Минимум host readiness:
Linux x86_64, KVM, 5 GiB MemAvailable и 30 GiB свободного диска для полного
профиля; фактическая пригодность подтверждается preflight.
