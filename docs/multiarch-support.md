# Multi-architecture support

Исходный и проверенный deployment target — Debian x86_64. ARM64 и другие ISA
не заявляются как поддержанные для QEMU/KVM/XDP/guest acceptance без отдельного
плана и evidence. Для ARM64 результат текущего runtime-аудита — `NOT TESTED`,
а несовместимый backend — `BLOCKED`.
