# Средства и лицензии

Состав стенда: Debian, QEMU/KVM, cloud-init, Python, Bash, nftables, OpenSSH,
eBPF/XDP, Suricata, nginx, Docker Compose, PostgreSQL, Zabbix и Ansible.
Точные версии конкретного запуска фиксируются в `reports/versions-*` и evidence.

Лицензионная проверка полного набора внешних пакетов остаётся частью live
приёмки; наличие этого документа не является её заменой.
