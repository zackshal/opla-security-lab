# Справочник команд

Основной интерфейс — `bin/opla-cli.py`. Сначала используйте read-only
`system audit`/host admission; создание лаборатории требует явного подтверждения
и проверки ресурсов. Рабочий каталог лаборатории передаётся через `LAB_DIR`, а
не через несуществующий общий `--lab` у подкоманд `ready`, `start` и `stop`.

Примеры форм CLI проверяйте через `opla --help`; live-команды не выполняются в
offline-проверках. Любой non-zero результат, неуверенная ownership-проверка или
неполное evidence имеют статус `BLOCKED`. Для удаления сначала строится plan,
затем применяется только явное подтверждение конкретного lab ID.
