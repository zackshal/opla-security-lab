# Восстановление прерванного создания

Не повторяйте create автоматически после timeout или неизвестного результата:
сначала сохраните command evidence, журнал и registry receipt. Проверка
ownership должна быть точной для lab ID и каждого ресурса; отсутствие receipt
или конфликт identity означает `BLOCKED`.

Recovery останавливает только подтверждённые owned-ресурсы, сохраняет
неопределённость и формирует reconciliation evidence. Delete выполняется после
успешного stop и отдельного явного подтверждения.
