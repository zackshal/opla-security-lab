# История публичного GitHub

**Русский** · [English](git-history.en.md)

Первичная публикация была отдельным исходным snapshot без приватных отчётов и runtime. Затем проверенная история исходников была присоединена через merge со стратегией ours, сохранив текущие файлы. Перенос завершён и не является шагом обычного релиза.

После исправления авторства публичная main перед этим обновлением была `56ec0e366bcb23666d97830df66008cd8cd89580`, с 41 коммитом. Это историческая контрольная точка, а не требование к будущему количеству коммитов. Проверенный bundle до исправления сохранён отдельно.

```bash
git log --graph --oneline --decorate main
git shortlog -sne main
git log main --format='%h | %an <%ae> | %cn <%ce>'
```

Не запускайте старые комплекты history.py повторно и не сливайте приватную ветку GitLab целиком: это может вернуть исключённые пути и старое авторство. Истории теперь различаются; переносите изменения выборочно, проверяя diff, атрибуцию и лицензии.

Обычные изменения публикуются через ветку и pull request, без force push. Если переписывание истории действительно необходимо: согласуйте его с участниками, создайте и проверьте private bundle, просканируйте все достижимые объекты, сравните дерево файлов и используйте force-with-lease с ожидаемым прежним remote SHA.

Фильтрация меняет хеши и делает старые подписи неприменимыми. Авторы, адреса и сообщения могут содержать персональные сведения. Gitleaks без находок не гарантирует отсутствие всех приватных данных; фильтр текущих путей не прослеживает все переименования. Старые приватные копии хранятся отдельно. Статистика Contributors может обновляться с задержкой: сначала проверяйте фактическую remote main.
