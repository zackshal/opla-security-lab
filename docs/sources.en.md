# Primary references

[Русский](sources.md) · **English**

For theory and operating instructions I used official Linux-kernel and open-source documentation. These references explain mechanisms and support reproduction; they are **not evidence that my own experiments passed**. Links were reviewed on 24 October 2026. Installed versions are recorded separately in a local manifest.

1. The Linux Kernel. eBPF verifier. https://docs.kernel.org/bpf/verifier.html
2. libbpf/bpftool. Source code and command documentation. https://github.com/libbpf/bpftool
3. QEMU documentation. https://www.qemu.org/documentation/
4. cloud-init documentation. https://cloudinit.readthedocs.io/
5. nftables project and documentation. https://netfilter.org/projects/nftables/
6. nginx `ngx_http_limit_req_module`. https://nginx.org/en/docs/http/ngx_http_limit_req_module.html
7. nginx `ngx_http_log_module`. https://nginx.org/en/docs/http/ngx_http_log_module.html
8. Zabbix 7.0 API. https://www.zabbix.com/documentation/7.0/en/manual/api
9. Zabbix 7.0 dashboard widget fields. https://www.zabbix.com/documentation/7.0/en/manual/api/reference/dashboard/widget_fields
10. Zabbix license. https://www.zabbix.com/license
11. PostgreSQL 16 documentation. https://www.postgresql.org/docs/16/
12. Git merge strategies. https://git-scm.com/docs/merge-strategies
13. GitHub releases. https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases
14. Suricata IPS documentation. https://docs.suricata.io/en/suricata-7.0.15/setting-up-ipsinline-for-linux.html
15. OWASP Core Rule Set. https://owasp.org/projects/crs
