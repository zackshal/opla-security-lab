# Запись действующего интерфейса

**Русский** · [English](README.en.md)

terminal-replay.gif/mp4 — исторический replay сохранённого вывода. Не переименовывайте его в запись текущего Zabbix и не используйте постановочный интерфейс как доказательство работы.

Для новой демонстрации запишите реальный экран после проверки актуального LAB_ID и свежести данных. Перед записью закройте credentials, почтовые адреса, private inventory и посторонние вкладки. Запишите commit, дату/часовой пояс и выбранный временной интервал; для исторического события прямо обозначьте, что показывается история.

Рекомендуемая последовательность: список/выбор текущего host → свежие значения и heartbeat → фактически существующие страницы dashboard → Problems с раскрытием выбранного события → recovery/нормальное состояние. Не создавайте нагрузку только ради видео без отдельного ограниченного сценария испытания. Не заявляйте проверку механизма по одной картинке.

Для просмотра достаточно 4–6 screenshots либо короткой записи. Имена страниц и число items берутся из действующего интерфейса; они не должны копироваться из старого справочника на 28 items. Подписи должны различать XDP counters, HTTP, Suricata, passive scan и delivery queue.

Новые материалы размещаются в assets/demo после проверки приватности и размера. Затем README переключается на существующие новые файлы. До получения реальных кадров не создавайте фиктивные изображения, значения, ссылки на несуществующее видео или утверждение «демо обновлено».
