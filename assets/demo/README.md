# Демонстрационные материалы README

`overview.svg` — схема архитектуры и сводка исторических наблюдений,
а не запись экрана. Числа взяты из [observed-results.json](observed-results.json),
сохраняющего переданный пользователем терминальный вывод от 24.10.2026.
SYN и HTTP — разные опыты. Длительности кадров произвольны; промежуточные
измерения, throughput, Suricata alerts и Zabbix screenshots не генерируются.

- [SVG-обзор](overview.svg), [старый GIF](overview.gif).
- [Карточка результатов](results.svg), [доступная текстовая версия](results.txt).
- [Manifest входных данных и media hashes](media-manifest.json).
- [Отдельная CLI-демонстрация с тестовыми данными](services/README.md).
- [Старая GIF-версия](terminal-replay.gif).

Изображения используют одну тёмную палитру с индиго, фиолетовым, зелёным,
красным и оранжевым акцентами. Фактические значения и ограничения остаются в
`observed-results.json`; картинки не имитируют Zabbix dashboard.

Для повторной сборки нужны уже установленные Pillow и шрифты DejaVu:

```bash
python3 tools/build-demo.py
```

Команда выполняется из корня проекта и только рендерит локальные файлы.
VM, сеть, Docker, SSH и live endpoint не используются. Для другого output
доступен `--output /tmp/opla-readme-media`.

## Редакция оформления 30.10.2026

Тёмная палитра, русские подписи, сетка и моноширинные подписи. Числовые данные
остались в observed-results.json; источник и ограничения указаны непосредственно
на изображениях.

Все изображения создаются локальным скриптом; внешние картинки и рейтинги не
используются.
